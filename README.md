# demo-openapi-korp

This repo demonstrates how a backend's OpenAPI specification can be used
in a frontend application:

- Generate TypeScript types with `openapi-typescript`
- Bootstrap a typed client instance with `openapi-fetch`

Checkout each commit in the history to follow the demo step by step.
Look at the commit message and the changes, and run the application.

Use [VS Code](https://code.visualstudio.com/) +
[Vue extension](https://marketplace.visualstudio.com/items?itemName=Vue.volar)
to explore how typing affects developer experience
with autocompletion and tooltips.

Install dependencies: `npm install`

Run application: `npm run dev`
